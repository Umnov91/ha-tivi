# ha-tivi

TizenBrew module: full-screen Home Assistant dashboard on Samsung Tizen TV.

Add in TizenBrew: Module Manager -> Add GitHub Module -> `Umnov91/ha-tivi`.

Dashboard URL: http://192.168.1.130:8123/ (edit `websiteURL` in package.json to change).
Red remote key reloads the page; page reloads daily at 04:00.
